# INDEX

Lookup index for this repo. Everything below the Entries heading is one
entry per line, pipe-separated in three fields: the file path relative to
the repo root, then a comma-separated list of keywords, then a one-line
description.

For assignments and projects, the description also carries due date,
status, and priority, so questions like "what's due this week" can be
answered from this file alone without fetching every file. Skills files
carry only a short subject description here; per-topic confidence lives in
the file itself.

Repo layout: assignments live at assignments/<course-slug>/<assignment-slug>.md,
projects at projects/<project-slug>/README.md, skills at
skills/<subject-slug>.md, and term-level planning references at events/.

Kept in sync by the college-repo-write skill. An empty Entries section
means nothing is tracked yet, not that the index is stale.

# Homework 1

**Due:** 2026-09-05 (Saturday) at 11:59pm on Gradescope
**Weight:** part of the 18.5% homework block - 13 assignments total, two lowest dropped
**Topics:** Linear systems, matrices, reduced echelon form (REF), Gauss-Jordan elimination
**Problems:** 1.1 - 1.11 (11 problems). Started 2026-08-31.

## Assignment-specific instructions

- **Do not omit the elementary row operation at each step** (e.g. write
  `R2 - 4R1` on the arrow between two matrices). This is a one-off rule
  for HW #1 and applies only where matrices are actually being reduced -
  1.4, 1.5(b), 1.6 (if computing the REF), 1.7, 1.10, 1.11. It does not
  apply to 1.1-1.3, which are graphs and algebra.
- Solve problems in the given order; do not copy problem text, just
  number the solutions.
- Show all work and justify answers - failing to do so incurs penalties.
- **5MB maximum file size** for this assignment specifically, above and
  beyond the general "reasonable size" rule. Photographing pages will
  blow past it; scan black-and-white.
- Check page orientation before upload - handwritten pages shot in
  landscape stay rotated in the PDF.
- MATLAB `rref(B)` may be used to check final results only; all
  computation must be by hand.
- Gradescope page "will be set up soon" per the handout - confirm it
  exists well before the deadline.
- Note: 1.9 asks for a cubic given f(1), f'(1), f(2), f'(2) - requires
  differentiating first, then building the linear system.
